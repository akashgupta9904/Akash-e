## ⚡ Deploy to Vercel (1-Click)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fakashgupta9904%2FAkash-e)

### Steps to Host on Vercel:
1. Open [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New..."** ➜ **"Project"**.
3. Import your GitHub repository: **`akashgupta9904/Akash-e`**.
4. Keep the default settings (Framework Preset: *Other* / *Static Site*).
5. Click **"Deploy"**! 🚀
6. Your website will be live in 10 seconds at `https://akash-e.vercel.app` (or your custom domain).
